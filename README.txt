Collegia - India college finder (Flask)

1. Install Python 3.9+ and open this folder in VS Code.
2. Terminal:   pip install -r requirements.txt
3. Terminal:   python app.py
4. Open http://127.0.0.1:5000 in your browser.

College.csv must stay next to app.py (or set the COLLEGE_CSV environment variable).
Needs internet for map tiles, college lookup and hostels (OpenStreetMap).
